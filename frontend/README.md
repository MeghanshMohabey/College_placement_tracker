# College Placement Tracker

A full-stack College Placement Tracker built using Next.js, Node.js, Express, and MongoDB. This application helps students manage placement activities, track applications, monitor interview rounds, and view placement statistics through an interactive dashboard.

---

## 🚀 Features

- Student Dashboard
- Company Application Tracking
- Interview Round Management
- Placement Statistics
- Responsive UI
- Authentication System
- Admin Panel
- Real-time Status Updates

---

## 🛠️ Tech Stack

### Frontend
- Next.js
- React.js
- Bootstrap

### Backend
- Node.js
- Express.js

### Database
- MongoDB

---

## ⚙️ Installation

### Clone Repository

git clone [https://github.com/MeghanshMohabey/College_placement_tracker.git]

### Frontend Setup

cd frontend
npm install
npm run dev

### Backend Setup

cd backend
npm install
npm start

---

## 🌐 Environment Variables

Create a `.env` file inside the backend folder and add:


MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=5000
